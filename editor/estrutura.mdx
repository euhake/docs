Um tema é um conjunto de arquivos de texto versionados. A AllBay resolve cada
rota da loja para um arquivo de página, envolve no layout e renderiza com Liquid.

## Pastas

Arquivos novos só podem ser criados nestas pastas (diretamente dentro delas):

| Pasta | Conteúdo |
| --- | --- |
| `pages/` | Páginas (index, category, package, checkout, order…) |
| `pages/account/` | Área do cliente (orders, affiliate) |
| `templates/` | Alternativa a `pages/` para as páginas |
| `layouts/` | Layouts que envolvem as páginas |
| `components/` · `snippets/` | Elementos reutilizáveis (`{% render %}`) |
| `sections/` | Blocos usados com `{% section %}` |
| `styles/` | CSS |
| `scripts/` | JavaScript |
| `assets/` · `widgets/` | Arquivos de apoio |

Arquivos que vieram com o tema base podem estar em outros lugares e continuam valendo.

<Info>
  O tema **Vega** usa: `components/`, `layouts/layout.liquid`, `pages/` (com
  `pages/account/`), `scripts/`, `styles/core.css` e um `tailwind.config.json` na raiz.
</Info>

## Tipos de arquivo

| Extensão | Uso |
| --- | --- |
| `.liquid` | Páginas, layouts, componentes e seções (recomendado) |
| `.html` | Também é Liquid; aceito por compatibilidade |
| `.css` | Estilos |
| `.js` | Scripts |
| `.json` | **Só** os arquivos de sistema: `tailwind.config.json` e `config/settings_schema.json` |

Qualquer outra extensão (`.ts`, `.jsx`, `.md`, `.svg`, imagens, fontes…) é recusada.
Imagens não ficam no tema: entram pelos campos `image`/`images` do
[schema](/editor/schema) e são servidas pela CDN (ver [Imagens](/editor/imagens)).

## Limites

| Limite | Valor |
| --- | --- |
| Arquivos por tema | **100** (no total) |
| Tamanho total do tema | **5 MiB** |
| Profundidade de caminho | **8** níveis |
| Nome do arquivo | até **32** caracteres (sem contar a extensão) |
| Arquivos novos por pasta | **45** |
| Temas editáveis por loja (em branco ou fork) | **10** |

## Nomes de arquivo

- Arquivos **novos**: só letras **minúsculas**, números, `.`, `_` e `-`; o primeiro
  caractere precisa ser letra ou número. Ex.: `product-card.liquid`.
- Nada de **espaços** nem caracteres fora do ASCII visível.
- `dotfiles` (`.env`, `.git/…`) e segmentos `.`/`..` são recusados em qualquer nível.
- Arquivos novos ficam a no máximo 2 níveis (`components/card.liquid`), ou 3 em
  `pages/account/`.

## Arquivos de sistema

`tailwind.config.json` e `config/settings_schema.json` são arquivos de sistema: o conteúdo
é editável, mas eles só podem existir nesses caminhos. No editor web, eles, a página
inicial e os arquivos do tema base aparecem como **travados** (sem apagar/renomear).

<Warning>
  Pelo [Editor Local](/editor/editor-local), apagar um arquivo da pasta **apaga do tema**.
  Não apague a página inicial: sem ela o tema não publica.
</Warning>

## Componentes

Inclua um componente com `{% render %}`:

```liquid
{% render 'components/navbar' %}
{% render 'navbar' %}
```

Com um nome simples (`'navbar'`), a AllBay procura a partir da raiz do tema, depois em
`snippets/` e depois em `components/` — com a extensão dada, `.liquid`, `.html` ou sem
extensão. Ver [Tags](/editor/tags#render-componentes).

## Layouts

Duas formas de envolver as páginas — ver [Páginas](/editor/paginas#layouts):

- **Automática:** se existir `layouts/base.liquid`, toda página é renderizada dentro
  dele, no lugar de `{{ content_for_layout }}`.
- **Declarada:** a página começa com `{% layout 'layouts/layout' %}` e o conteúdo dela entra
  no `{% block %}{% endblock %}` do layout (é o que o Vega usa).

## Resolução de páginas (aliases)

Cada rota resolve para um arquivo de entrada, e você não precisa nomear tudo
exatamente igual. A AllBay tenta, em ordem:

1. `templates/<nome>` (`.liquid`, depois `.html`);
2. `templates/<alias>`;
3. `pages/<nome>`;
4. `pages/<alias>`.

Aliases de nome: `product ≡ package`, `collection ≡ category`,
`cart ≡ checkout`, `404 ≡ not-found`. O nome canônico sempre vence o alias.

Por isso o Vega (que só tem `pages/`) atende a rota de produto com
`pages/package.liquid` e a de coleção com `pages/category.liquid`. Ver a tabela
completa em [Páginas](/editor/paginas).

## Configuração (schema)

O arquivo `config/settings_schema.json` define as opções que aparecem no painel
(cores, textos, imagens…). Ver [Schema](/editor/schema).
