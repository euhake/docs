O [Cursor](https://cursor.com) é um editor de código com IA integrada (baseado no VS Code). Com o
[Editor Local](/editor/editor-local), você descreve as mudanças e o Cursor edita os arquivos do tema.

## Pré-requisitos

- O [Editor Local](/editor/editor-local) com login feito e rodando na pasta do tema.
- Cursor instalado.

## Passo a passo

<Steps>
  <Step title="Baixe o tema e deixe o CLI rodando">
    ```bash
    mkdir meu-tema && cd meu-tema
    npx allbay-editor@latest --template SEU_ID_DO_TEMPLATE
    ```
    Deixe esse terminal aberto — ele sincroniza cada save.
  </Step>
  <Step title="Abra a pasta no Cursor">
    Use o chat (`Ctrl/Cmd + L`) ou a edição inline (`Ctrl/Cmd + K`).
  </Step>
  <Step title="Peça a mudança">
    > "Deixe o cabeçalho fixo no topo ao rolar a página."

    O Cursor edita os arquivos; aceite as sugestões e salve — o CLI sincroniza.
    Para mudanças em vários arquivos, use o chat com `@Codebase`.
  </Step>
</Steps>

## Conecte a documentação ao Cursor (MCP)

Esta documentação tem um servidor **MCP**: com ele, o Cursor consulta as páginas da AllBay
enquanto trabalha. Crie o arquivo **`.cursor/mcp.json`** na raiz do tema (ele fica só na sua
máquina):

```json .cursor/mcp.json
{
  "mcpServers": {
    "allbay-docs": {
      "url": "https://allbay.mintlify.app/mcp"
    }
  }
}
```

Depois, confira em **Settings → MCP** que o `allbay-docs` aparece ativo. O servidor oferece
busca na documentação e leitura das páginas.

<Tip>
  Para outras IAs, a documentação inteira também está em texto em
  [llms.txt](https://allbay.mintlify.app/llms.txt) (índice) e
  [llms-full.txt](https://allbay.mintlify.app/llms-full.txt) (conteúdo completo).
</Tip>

## Dê contexto ao Cursor (recomendado)

Crie um arquivo **`.cursorrules`** na raiz do tema (ele fica só na sua máquina):

```md .cursorrules
Este projeto é um tema AllBay em Liquid.
- Lógica {% %}, saída {{ }}. Componentes: {% render 'components/nome', var: valor %}
  (componentes só veem globais e parâmetros).
- Falsos: nil, false, 0 e "". Lista vazia [] é verdadeira — use lista.size > 0.
- Dados: {% load "packages", limit: 8 %}. Alias logo após a entidade:
  {% load "product" as p, slug: "x" %}. Ids sempre entre aspas.
- Objetos: store, theme, config, settings, user, logged_in, categories, products, packages,
  product, gateways, socials, order, orders, posts, post, cart, terms, query, pathname.
- Preços com | money. Imagens já vêm como URL pronta (teste antes de usar);
  cdn_url só para hash de load "products"/"product"/"categories", com 4 argumentos.
- Schema: chaves só com letras, números e _ (sem hífen).
- Arquivos novos: só .liquid/.html/.css/.js, nomes em minúsculas até 32 caracteres.
- Login é da plataforma (não crie pages/login).
- Docs: https://allbay.mintlify.app/editor/introducao (MCP: https://allbay.mintlify.app/mcp)
Faça uma mudança por vez.
```
