title: "Sintaxe"
description: "Liquid com {% %} para lógica e {{ }} para saída — e as diferenças que importam."
---

Os temas da AllBay são renderizados com **Liquid**, usando os delimitadores de sempre:

- `{% ... %}` — **lógica** (tags: condicionais, laços, includes).
- `{{ ... }}` — **saída** (imprime o valor de uma variável).

## Saída de variáveis

```liquid
<h1>{{ store.name }}</h1>
<p>Moeda: {{ store.currency }}</p>
```

## Condicionais

```liquid
{% if store.maintenance %}
  <p>Loja em manutenção.</p>
{% elsif logged_in %}
  <p>Olá, {{ user.name }}!</p>
{% else %}
  <p>Bem-vindo!</p>
{% endif %}

{% unless logged_in %}
  <a href="/login">Entrar</a>
{% endunless %}
```

Operadores: `==`, `!=`, `>`, `<`, `>=`, `<=`, `and`, `or`, `contains`, `not`.

<Warning>
  **O que é "falso" na AllBay é diferente do Liquid tradicional:** `nil`, `false`,
  **`0`** e **`""`** (texto vazio) são falsos. Uma **lista vazia `[]` é verdadeira**.
  Para testar se uma lista tem itens, use `{% if lista.size > 0 %}`.
</Warning>

## Laços

```liquid
{% for category in categories %}
  <li>{{ category.name }}</li>
{% endfor %}
```

Variáveis do laço: `forloop.index` (começa em 1), `forloop.index0` (em 0), `forloop.first`, `forloop.last`, `forloop.length`.

## Variáveis locais

```liquid
{% assign destaque = "Promoção" %}
{{ destaque }}

{% capture saudacao %}Olá, {{ user.name }}{% endcapture %}
{{ saudacao }}
```

## Filtros

Transforme valores com o operador pipe `|`, encadeável:

```liquid
{{ 29.90 | money }}
{{ store.name | upcase | truncate: 20 }}
```

Ver a lista completa em [Filtros](/editor/filtros).

## Componentes e layouts

Use `{% render %}` para incluir um componente e um layout para envolver a página:

```liquid
{% render 'components/navbar' %}
```

Ver [Tags](/editor/tags) e [Estrutura](/editor/estrutura) para os detalhes de componentes,
layouts e o carregamento de dados com `{% load %}`.

## Tags e filtros permitidos

- Só existem as **tags** e os **filtros** listados em [Tags](/editor/tags) e
  [Filtros](/editor/filtros). Uma tag ou filtro fora da lista é **erro**: a página não renderiza.
- `{% render %}` e `{% include %}` só leem arquivos **do próprio tema**.
- Páginas muito pesadas ou lentas para gerar não são exibidas — mantenha laços e `load`
  enxutos.
