title: "Sintaxe"

---

Os temas da AllBay são renderizados com **Liquid**, usando os **delimitadores padrão**:

- `{% ... %}` — **lógica** (tags: condicionais, laços, includes).
- `{{ ... }}` — **saída** (imprime o valor de uma variável).

<Note>
  A AllBay usa o Liquid **padrão**. Assim, realce de sintaxe, formatadores e assistentes de IA funcionam sem configuração especial.
</Note>

## Saída de variáveis

```liquid
<h1>{{ store.name }}</h1>
<p>Moeda: {{ store.currency }}</p>
```

## Condicionais

```liquid
{% if store.maintenance %}
  <p>Loja em manutenção.</p>
{% elsif store.auth %}
  <p>Faça login para continuar.</p>
{% else %}
  <p>Bem-vindo!</p>
{% endif %}

{% unless user %}
  <a href="/login">Entrar</a>
{% endunless %}
```

Operadores: `==`, `!=`, `>`, `<`, `>=`, `<=`, `and`, `or`, `contains`.

## Laços

```liquid
{% for category in categories %}
  <li>{{ category.name }}</li>
{% endfor %}
```

Variáveis do laço: `forloop.index` (começa em 1), `forloop.index0` (em 0), `forloop.first`, `forloop.last`, `forloop.length`.

## Variáveis locais

```liquid
{% assign destaque = "Promoção" %}
{{ destaque }}

{% capture saudacao %}Olá, {{ user.name }}{% endcapture %}
{{ saudacao }}
```

## Filtros

Transforme valores com o operador pipe `|`, encadeável:

```liquid
{{ 29.90 | format_price }}
{{ store.name | upcase | truncate: 20 }}
```

Ver a lista completa em [Filtros](/editor/filtros).

## Componentes e layouts

Use `{% render %}` para incluir um componente, e a cadeia de layouts para envolver a página:

```liquid
{% render 'components/navbar' %}
```

Ver [Tags](/editor/tags) e [Estrutura](/editor/estrutura) para os detalhes de componentes, layouts e o carregamento de dados com `{% load %}`.

<Warning>
  Por segurança, apenas um conjunto controlado de tags e filtros é permitido. Tags perigosas (que leem arquivos arbitrários, por exemplo) são bloqueadas pelo servidor. Ver [Tags](/editor/tags).
</Warning>
